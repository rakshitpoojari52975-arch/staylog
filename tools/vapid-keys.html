StayLog notification keys

Makes a VAPID key pair in this browser. Nothing leaves this page and nothing is saved, so copy both before closing it. Make one pair, once; a new pair means every device turns notifications on again.

Public key Public by design. Goes in cloud-config.js as vapidPublicKey, and in Supabase as the secret VAPID_PUBLIC_KEY.
Private key: keep it secret Only in Supabase, as the secret VAPID_PRIVATE_KEY. Never in cloud-config.js, the repository, a message or a screenshot. Anyone holding it can send notifications as StayLog.
